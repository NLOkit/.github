# NLOkit

**First-principles optical response calculations and computational materials research**

NLOkit is a research software organization focused on developing computational tools for studying the optical properties of crystalline materials, with particular emphasis on nonlinear optical responses and materials design.

Our software connects electronic-structure calculations with optical response theory, numerical implementations, reproducible workflows, and educational resources.

## Research and software

- **Linear optical response:** Susceptibility, dielectric properties, and related optical quantities.
- **Nonlinear optical response:** Static and frequency-dependent second-harmonic generation (SHG).
- **Atom-resolved analysis:** Contributions from atoms and structural motifs to optical responses.
- **Reproducible workflows:** Tools, examples, and tutorials for first-principles calculations.

## Projects

| Project | Description |
| --- | --- |
| [nlokit](https://github.com/NLOkit/nlokit) | Python tools for linear and nonlinear optical responses with CASTEP, VASP, and GPAW interfaces. |
| [nlokit-fortran](https://github.com/NLOkit/nlokit-fortran) | Reusable Fortran kernels for SHG calculations. |
| [nlokit_tutorials](https://github.com/NLOkit/nlokit_tutorials) | Tutorials and examples for optical property calculations. |
| [for-students](https://github.com/NLOkit/for-students) | Training resources covering Python, Git, Linux, HPC, and VASP. |

**Repository availability:** Some projects are currently private during development. Public source code, documentation, and releases will be linked here as they become available.

## Development

Our goal is to make first-principles optical response calculations more transparent, reproducible, and accessible to researchers working on nonlinear optical materials.

For project-specific questions, please use the corresponding repository's issue tracker when access is available.
